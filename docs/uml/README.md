# UML diagrams

All diagrams use **Mermaid** so they render natively in GitHub, VS Code, and
the rendered architecture docs. Files in this folder:

* `system-context.mmd` — C4 system context.
* `component-diagram.mmd` — internal components & dependencies.
* `sequence-recording.mmd` — happy-path recording → upload → email sequence.
* `data-model.mmd` — class / data model.
* `state-recorder.mmd` — state machine of the chunked recorder.
* `deployment.mmd` — deployment topology.

To preview locally: open any `.mmd` file in VS Code with the
**Markdown Preview Mermaid Support** extension, or paste into
<https://mermaid.live>.
